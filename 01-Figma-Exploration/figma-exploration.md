# Figma Exploration – Hawkeye Travel App UI Kit

## 1. Introduction

This document presents the exploration of a mobile application user interface using Figma. The selected design is the Hawkeye Travel App Template, which provides a collection of mobile screens for travel planning and social interaction.

The purpose of this activity is to understand how Figma is used for UI/UX design, explore different interface components, and learn how mobile application screens are organized to provide a better user experience.

## 2. Selected Design Information

- **Design Name:** Hawkeye Travel App Template
- **Designer:** Alan Love
- **Design Category:** Travel and Trip Planning Mobile Application
- **Design Platform:** Figma
- **Design Source:** Free Figma Templates
- **Number of Screens:** 18
- **Design Link:** https://www.freefigmatemplates.com/gallery/travel-app-template

## 3. Purpose of the Application

The Hawkeye Travel App is designed to help users organize their travel activities and manage their travel plans through a mobile interface.

It provides features related to travel scheduling, personal account management, trip arrangements, location browsing, and communication with friends.

The application aims to make travel planning more organized and convenient.

## 4. Screens Explored

I selected and explored five screens from the Hawkeye Travel App UI Kit.

### 4.1 Login Page

The login page provides an interface for users to access their accounts.

Main interface elements:
- User login fields.
- Account access options.
- Login button.
- Navigation for account registration or recovery.

**Purpose:** To provide users with a simple way to access their travel accounts.

### 4.2 Schedule Page

The schedule page is designed to organize travel activities and planned events.

Main interface elements:
- Travel schedule information.
- Dates and timing.
- Organized activity details.
- Schedule-related navigation.

**Purpose:** To help users view and organize their travel schedules.

### 4.3 Personal Center

The personal center provides access to user-related information and account settings.

Main interface elements:
- Personal profile information.
- Account-related options.
- Personal settings.
- User navigation options.

**Purpose:** To allow users to manage their personal information and account preferences.

### 4.4 Travel Arrangement Page

The travel arrangement page focuses on organizing travel plans.

Main interface elements:
- Travel arrangement information.
- Destination-related details.
- Trip planning options.
- Travel organization features.

**Purpose:** To help users organize their travel activities in one place.

### 4.5 Friend Communication Page

The friend communication page provides an interface for social interaction between users.

Main interface elements:

**Purpose:** To support communication and coordination between friends during travel planning.

## 5. Figma Environment Exploration

Figma is a web-based design and prototyping tool used to create user interfaces and interactive prototypes.

During this activity, the following Figma features were explored:

### Design Canvas
The canvas provides an area where interface screens and design elements can be viewed and organized.

### Layers Panel
The layers panel displays the individual elements that make up a design, such as text, images, buttons, and shapes.

### Assets Panel
The assets panel provides access to reusable components and design resources.

### Design Properties
Design properties allow designers to examine and modify colors, typography, spacing, dimensions, and alignment.

### Prototype Features
The prototype section allows designers to connect different screens and demonstrate how users navigate through an application.

## 6. User Experience Design Principles Observed

The selected design demonstrates several important UX principles:

1. **Consistency:** Similar interface elements help maintain a consistent experience.
2. **Visual Hierarchy:** Important information can be presented through different font sizes and visual arrangements.
3. **Navigation:** Different screens provide access to different application features.
4. **Organization:** Travel information is divided into separate sections.
5. **User-Centered Design:** The interface is organized around common travel planning activities.
